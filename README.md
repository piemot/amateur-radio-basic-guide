Study notes for the Canadian Amateur Radio Operator's Certificate (Basic Qualification), written in Typst.


## Overview

This repository contains a set of notes designed to help you prepare for the
Canadian Amateur Radio Basic Qualification exam.

The notes are written in [Typst](https://typst.app), a modern markup-based typesetting system.

## Sources

- [University of Waterloo Amateur Radio Club: Amateur Radio Basic Qualification](https://uwarc.uwaterloo.ca/assets/basic-essentials-main.pdf)
- [CLARES Basic Course](https://clares.ca/course/basic)
- [Toronto Emergency Communication: Basic Amateur Radio Course](https://csclub.uwaterloo.ca/~ehashman/emcomm-ham-radio.pdf)
- [Boat US Marine Calls](https://boatus.org/marine-communications/calls)

- [Wikipedia: Characteristic Impedance](https://en.wikipedia.org/wiki/Characteristic_impedance)

## Requirements

To build the notes locally, you'll need the Typst CLI.
```sh
typst compile radio.typ
```
